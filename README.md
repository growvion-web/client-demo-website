# Chester-le-Street Recovery — Modern Landing Page V3 — Dark Blue

A lightweight, mobile-first static website for GitHub + Vercel.

## Files
- `index.html` — complete landing page
- `styles.css` — responsive styling
- `script.js` — mobile menu + current year
- `assets/recovery-hero.png` — original photorealistic generated hero artwork
- `assets/favicon.svg` — original SVG favicon
- `vercel.json` — Vercel headers / clean URLs

## Deploy
1. Create a GitHub repository.
2. Upload all files/folders in this directory.
3. Import the repository into Vercel.
4. Framework preset: Other.
5. Build command: leave blank.
6. Output directory: leave blank / project root.
7. Deploy.
